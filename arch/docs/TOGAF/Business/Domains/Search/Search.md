# Search – Core Domain

- Personalizované vyhledávání.  

## Klíčové procesy
- Indexace produktů a jejich metadat
- Personalizace výsledků podle uživatele
- Autocomplete a doporučení
- Synchronizace s:
    - Catalog
    - Provisioning
    - Marketing

## Architektonické principy
- Read model optimalizovaný pro rychlé vyhledávání
- Event-driven aktualizace indexů
- Personalizace bez narušení integrity dat
- Podpora škálovatelného fulltextového vyhledávání
