# Dopad architektury

Tato kapitola definuje, jak **výkon**, **stabilita** a **UX** ovlivňují:
- strategické cíle platformy,
- ekonomické výsledky,
- provozní náklady,
- architektonická rozhodnutí (ADR),
- řízení rizik a prioritizaci investic.

Výkon není technický detail. Je to **business capability** s přímým dopadem na revenue, reputaci a provozní efektivitu.
