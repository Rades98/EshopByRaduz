# EshopByRaduz – případová studie

Tato případová studie mapuje návrh a realizaci e-shopového systému z pohledu architektury, stakeholder motivací a strategických cílů.  
Model je vytvořen v Archi a propojen s dokumentací v MkDocs.  
Kromě architektonických pohledů jsou některé klíčové funkcionality implementovány v C#.

> Cílem není jen technická správnost, ale i strategická čitelnost a udržitelnost systému.
